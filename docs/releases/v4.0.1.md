RIFF **v4.0.1** is a stable patch for **MATLAB R2026b+**, fixing how measurements of the same system are joined across frequency bands and refreshing the tutorials. The v4.0 default algorithms and interactive plotting/editor features are retained.

### Fixes

- Joining SDF measurements now works with reversed file order, different sample spacing, nested ranges, and disjoint bands. Previously, changing the selection order could cause a dimension error.
- Responses are interpolated onto a common Hz grid and averaged as complex values in overlaps. Duplicate/invalid samples are handled, and frequencies without measurement coverage are omitted. Measurements must already have consistent calibration, channels, and units.
- The shared implementation lives in `fitTF.m`: use `fitTF('combine',files,dF)` to inspect a joined response or `fitTF('SDF_DATASETS',files,...)` to fit it. Decoded `F`/`TF` structures are also accepted by the combine command.
- The existing five-output `combineTFs` utility remains available; its documented three-argument call now works. Combining no longer disables all warnings or changes global plotting defaults.
- The app shows v4.0.1 without clipping its title and correctly lists R2026b+ compatibility.

### Lightweight current-app demos

Three captioned MP4s replace the older GIF collection. They total **0.71 MB**, versus **63.46 MB** of old GIFs (about 99% smaller). All use the app's default window size, with actual app plots/controls; computation waits are omitted.

- [Fit and inspect — 23 seconds](https://github.com/Nikhil-Mukund/RIFF/blob/v4.0.1/tutorials/demos/fitting.mp4): AAA + tfest and embedded Bode plots.
- [Join frequency bands — 20 seconds](https://github.com/Nikhil-Mukund/RIFF/blob/v4.0.1/tutorials/demos/measurements.mp4): three bundled SDF measurements and the fitting region.
- [Verify and refine — 27 seconds](https://github.com/Nikhil-Mukund/RIFF/blob/v4.0.1/tutorials/demos/refinement.mp4): trial parameters, pole dragging, gain, and reset.

The fit/refinement demo uses a synthetic example; the joining demo uses the bundled instrument files. See the [updated README](https://github.com/Nikhil-Mukund/RIFF/blob/v4.0.1/README.md) and [reproduction scripts](https://github.com/Nikhil-Mukund/RIFF/tree/v4.0.1/tutorials).

### Validation and package

- All **61 regression cases passed on MATLAB R2026b (macOS)**, including ten new joining tests, real app preview, AAA via SDF input, and pole dragging at the default window size.
- A fresh-session test of the installed package passed AAA fitting, joining the bundled SDF bands, native previews, Verify/trial switching, and manual editing.
- All packaged source/demo files match the tested checkout; MP4 decoding and README links were checked.
- The installer is **2.28 MB** (2,279,266 bytes), down from **64.45 MB** in v4.0. Required MATLAB products are unchanged.

### Upgrade

Download **RIFF.mltbx** below and install it in MATLAB R2026b+. Close RIFF before upgrading, preserve custom INI files, and use `mpminstall('RIFF.mltbx',AllowVersionReplacement=true)` if MATLAB reports an existing package with the same ID. Restart MATLAB after upgrading so cached app/function definitions are refreshed. `which RIFF -all` and `which fitTF -all` identify older copies taking precedence on the path.

Overlap handling is corrected in this patch, so a newly joined/fitted result can differ from earlier releases. All v4.0 fitting algorithms and the command-line/editor APIs remain available. The published **v4.0** and **v3.0** tags/assets are unchanged; R2023b users should keep using [v3.0](https://github.com/Nikhil-Mukund/RIFF/releases/tag/v3.0).

`SHA256SUMS.txt` contains the installer checksum.
