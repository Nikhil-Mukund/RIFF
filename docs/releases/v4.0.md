RIFF v4.0 is the stable release for **MATLAB R2026b and newer**. The package version is **4.0.0**. RIFF remains focused on automatic fitting of measured transfer functions, with the same core available through the app and `fitTF.m`.

### Highlights

- **AAA + N4SID-initialized tfest by default.** AAA now uses System Identification Toolbox through `ssest`. RF Toolbox is optional; the older RF implementation remains available with `AAA_BACKEND='rf'`. Both default candidates remain enabled because neither wins on every measurement.
- **Native Bode plots inside the app.** Zoom, pan, inspect data tips, and resize the app. The additional figure window is off by default; standalone FIG/PNG exports remain available.
- **Shared command-line and app functionality.** All new runtime logic, including plotting, verification, parameter formatting, and editing, lives in `fitTF.m`.
- **Optional manual refinement.** Drag poles and zeros or edit coordinates and gain, see the response update, preserve conjugate pairs and delays, and reset each trial independently. Export edited models separately from the fitted originals.
- **Verification fixes.** Model parameters follow the selected intermediate fit, and drafts survive switching between fits. Fresh app startup and refresh also handle empty folders and single measurement files.

### Install or upgrade

Download **RIFF.mltbx** below, open it in MATLAB R2026b+, and install. Launch RIFF from the Apps gallery or enter `RIFF`. The package also exposes `fitTF` on the MATLAB path.

Close existing RIFF windows when upgrading. Remove or disable older copies that take precedence on the path, then run `clear fitTF RIFF`. Use `which RIFF -all` and `which fitTF -all` to check the active installation. Preserve custom INI files; review explicit routine/uncertainty settings if they override the new defaults. If MATLAB reports an older package with the same ID, uninstall it first or use `mpminstall('RIFF.mltbx',AllowVersionReplacement=true)`.

The app uses `measured_TFs` under MATLAB's current folder for imported files. Choose a writable working folder and import your data through the app controls. The installer includes examples, documentation, benchmarks, and the existing import/filtering utilities.

### Compatibility and validation

- Minimum MATLAB release: **R2026b**. Validation performed on R2026b; later releases are allowed by the package metadata.
- All **51 regression cases passed on MATLAB R2026b (macOS)** before packaging, covering GUI/CLI fitting, AAA, embedded/standalone plots, Verify, mouse dragging, resets, exports, and startup.
- The built installer also passed a fresh-session smoke test covering AAA, native preview, Verify, manual editing, and v4.0 branding.
- A reproducible [120-estimate benchmark](https://github.com/Nikhil-Mukund/RIFF/blob/v4.0/benchmarks/AAA_COMPARISON.md) documents AAA comparisons and their limitations.
- Use [v3.0 for MATLAB R2023b+](https://github.com/Nikhil-Mukund/RIFF/releases/tag/v3.0). That existing release and tag are unchanged.

See the [README](https://github.com/Nikhil-Mukund/RIFF/blob/v4.0/README.md) for dependencies, examples, and the pole/zero editor screenshot. `SHA256SUMS.txt` provides the installer checksum.
